# planner-app
An Android planner application built with Jetpack Compose and Room

## Features
- **Daily & Weekly View:** Manage your schedule with integrated "Today" and "Weekly" screens.
- **Localized Calendar:** Supports Jalali, Gregorian, and Hijri calendars.
- **Persistence:** Uses **Room Database** for offline storage of events, goals, and reminders.
- **Clean UI:** Modern interface following Material 3 guidelines with a Navigation Drawer.

## Tech Stack
- **UI:** Jetpack Compose
- **Architecture:** Single-Activity, Route-based Navigation
- **Database:** Room (SQLite)
- **Language:** Kotlin
